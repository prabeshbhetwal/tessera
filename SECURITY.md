# Security policy

## Reporting a vulnerability

Please report security issues privately through [GitHub's private vulnerability reporting](https://github.com/prabeshbhetwal/tessera/security/advisories/new). Do not open a public issue.

Include the Tessera version (Settings › About › Copy version), your macOS version and steps to reproduce. You should get a reply within seven days.

## Supported versions

Only the latest release receives fixes. Tessera updates itself through Sparkle, so update first and check whether the issue remains.

## Scope

In scope: the Tessera app, its command-line tool, the `tessera://` URL scheme, AppleScript and Shortcuts actions, the local automation socket and the update feed.

Tessera holds the Accessibility permission, so issues that let another process or a web page drive or read windows through Tessera without the user's intent are in scope.
