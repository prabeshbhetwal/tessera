# Tessera Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tessera milestone 1. It is a macOS menu-bar app: hold Left ⌃⌥⌘, then flick or point to snap the frontmost window into a grid sized for each display. It includes the rich preview and full customisation.

**Architecture:**
- The pure logic (GridKit, SelectionEngine, TriggerMachine, PreviewModel, SettingsStore) lives in a local SwiftPM package called `TesseraCore`. It has no AppKit and is tested with `swift test`.
- The app target `Tessera` is generated by XcodeGen. It contains the thin system services (event tap, displays, Accessibility, ScreenCaptureKit), the overlay panels, the SwiftUI settings and onboarding, and a main-actor `Coordinator` that wires everything together.

**Tech Stack:** Swift 6 language mode, complete strict concurrency, macOS 15+, SwiftPM, XcodeGen, Swift Testing, AppKit, SwiftUI, Core Animation, ScreenCaptureKit. No third-party runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-03-tessera-milestone1-design.md`

## Global Constraints

- macOS deployment target is `15.0`. Swift language mode is 6, with `SWIFT_STRICT_CONCURRENCY = complete`.
- There are no third-party dependencies.
- Never copy code from `loop/`, which is GPL-3.0 and kept only as a read-only reference.
- No force-unwraps, `try!` or `as!` on system calls. Keep files under 500 lines.
- Load private APIs only through `dlsym`, wrapped in optionals. Never use `@_silgen_name`.
- Bundle ID is `com.prabeshbhetwal.Tessera`, with `LSUIElement = YES`. Use ad-hoc signing (`CODE_SIGN_IDENTITY = -`), because no signing identity exists.
- Coordinates:
  - All TesseraCore geometry uses **AppKit global coordinates**: bottom-left origin, relative to the primary screen.
  - Conversion to and from AX (top-left) happens only in `CoordinateSpace`.
  - CGEvent locations are top-left. InputService converts them to AppKit coordinates before emitting anything.
- **Every `swift`, `xcodebuild` and `xcodegen` command must run outside the sandbox.** Use `dangerouslyDisableSandbox: true`, because the sandbox blocks the xcrun cache.
- **Build output must live outside iCloud.** `~/Desktop` is iCloud Drive, so codesign fails there with "resource fork, Finder information… not allowed". Always pass `--scratch-path ~/Library/Caches/tessera-build/core-$TRACK` to `swift` and `-derivedDataPath ~/Library/Caches/tessera-build/dd-$TRACK` to `xcodebuild`. `$TRACK` is your track letter (A–E), or `main` for the coordinator. Never put `.build/` inside the repo.
- Logging uses `os.Logger(subsystem: "com.prabeshbhetwal.Tessera", category: <service>)`.

## Review Focus

These are the input classes most likely to cause trouble. Each one has a test in the task listed.

1. **Cursor outside every display, or in the gap between two displays.** Expected: `Selection.none`, never a crash or a jump to a wrong screen. (Task B1)
2. **Chord keys pressed in any order, or one key released early.** Expected: apply fires exactly once. The menu does not reopen until every chord key has been released and the full chord is pressed again. (Task B2)
3. **A saved column count that falls outside the current range** after a settings change or a different monitor. Expected: clamp to the range and never produce zero-width columns. (Task A1)
4. **`settings.json` from a newer `schemaVersion`, or truncated JSON.** Expected: rename the file, fall back to defaults, never overwrite it silently. (Task C2)
5. **A span whose anchor and current cell are on different displays.** Expected: the anchor is dropped and the selection is the current cell only. (Task B1)

## Track B: Selection and trigger (worktree agent "input-logic")

### Task B1: SelectionEngine

**Files:**
- Create: `Selection/SelectionEngine.swift`
- Test: `SelectionEngineTests.swift`

**Interfaces:**
- Consumes: `RingSettings`, `DisplayContext`, `Selection`, `ColumnSpan`, `Band` (Track 0)
- Produces:
  - `struct SpanAnchor: Equatable, Sendable { let display: DisplayID; let column: Int; let band: Band }`
  - `struct SelectionEngine: Sendable`:
    - `init(ring: RingSettings)`
    - `func select(origin: CGPoint, cursor: CGPoint, displays: [DisplayContext], anchor: SpanAnchor?) -> Selection`
    - `func anchor(at cursor: CGPoint, displays: [DisplayContext]) -> SpanAnchor?`

**Rules:**
- Zones follow spec §4.2. Distances are boundary-inclusive at the lower edge: `d == 10` is a flick and `d == 90` is a point.
- Wedge angle is measured clockwise from up, in AppKit coordinates (y up): `index = Int(((deg + 22.5).truncatingRemainder(dividingBy: 360) + 360).truncatingRemainder(dividingBy: 360) / 45)`.
- Point mode:
  - The display is the first one whose `visibleFrame` contains the cursor. If none contains it, return `.none`.
  - Column: `GridGeometry`'s rule, inlined as `floor((x − usable.minX) / (usable.width / columns))` and clamped. Do not import Track A internals; the two must agree because the tests share the CHG90 fixture.
  - Band from the vertical position within `visibleFrame`: top 30% gives `.top`, bottom 30% gives `.bottom`, everything else gives `.full`.
  - Anchor:
    - On the same display: columns run from `min…max` of the two columns, and the band is shared if both bands are equal, otherwise `.full`.
    - On a different display: ignore the anchor.

- [x] **Step 1:** Write the tests:
  - `testDeadZone`: d = 9.99 gives `.none`.
  - `testFlickBoundaries`: d = 10 and d = 89.99 give a wedge; d = 90 gives a span.
  - `testWedgeAngles`: 0° → index 0 (maximize), 22.49° → 0, 22.5° → 1, 90° → 2 (rightHalf), 180° → 4 (center), 270° → 6, 337.5° → 0.
  - `testPointCHG90Column`: a 3840-wide display with 5 columns and cursor x = 1600 gives column 2.
  - `testBands`: cursor at 80% height gives `.top`, 50% gives `.full`, 20% gives `.bottom`.
  - `testAnchorSpan`: anchor at column 1 `.top`, cursor at column 3 `.top`, gives `1...3, .top`. With the cursor at column 3 `.full`, the band becomes `.full`.
  - `testCursorOutsideDisplays`: gives `.none`.
  - `testAnchorOnOtherDisplayIgnored`.
- [x] **Step 2:** Run `--filter SelectionEngineTests`. Expected: FAIL.

### Task B2: TriggerMachine

**Files:**
- Create: `Trigger/TriggerMachine.swift`
- Test: `TriggerMachineTests.swift`

**Interfaces:**
- Consumes: `TriggerChord`
- Produces:
  - `enum InputEvent: Sendable, Equatable`:
    - `.flagsChanged(pressedModifiers: Set<UInt16>, location: CGPoint)`
    - `.keyDown(keyCode: UInt16, location: CGPoint)`
    - `.mouseMoved(CGPoint)`
    - `.leftMouseDown(CGPoint)`
    - `.scroll(deltaY: Double)`
  - `enum TriggerOutput: Sendable, Equatable`:
    - `.open(origin: CGPoint)`, `.move(CGPoint)`, `.anchor(CGPoint)`, `.step(Int)`, `.apply`, `.cancel`
  - `struct TriggerResult: Equatable { let outputs: [TriggerOutput]; let suppress: Bool }`
  - `struct TriggerMachine: Sendable`:
    - `init(chord: TriggerChord)`
    - `mutating func handle(_ e: InputEvent) -> TriggerResult`
    - `var isOpen: Bool { get }`

**Rules:**
- `pressedModifiers` holds device-specific modifier keycodes (54/55 Command, 56/60 Shift, 58/61 Option, 59/62 Control, 63 Fn) and is computed by InputService.
- **Opening:**
  - Open when `pressedModifiers ⊇ chord` and the machine is armed.
  - The machine is armed at start, and again once `pressedModifiers ∩ chord` becomes empty.
  - Opening disarms it.
- **While open:**
  - Losing any chord key → `.apply` and close.
  - Key 53 (Esc) → `.cancel`, suppressed.
  - Any other keyDown → `.cancel`, **not** suppressed (pass-through).
  - Mouse move → `.move`, not suppressed.
  - Left mouse down → `.anchor`, suppressed.
  - Scroll → `.step(deltaY > 0 ? +1 : -1)`, suppressed. A `deltaY` of 0 is ignored.
- **While closed:** nothing is suppressed and no outputs are produced, except `.open`.

The machine is a value type. It is **confined to the event-tap thread**, which owns it so it can decide synchronously whether to suppress. This refines spec §5.3 and removes the cross-thread state that Loop got wrong.

- [x] **Step 1:** Write the tests:
  - `testOpensOnlyWhenFullChord`: pressing in all 6 possible orders opens exactly once.
  - `testPartialReleaseApplies`.
  - `testNoReopenUntilAllReleased`: release Command (apply), then press Command again while Control and Option are still held: no open. Release all, then press all three: open.
  - `testEscCancelsSuppressed`.
  - `testOtherKeyPassesThrough`: keyDown 0 while open gives `[.cancel]` and `suppress == false`.
  - `testClickAnchorsSuppressed`.
  - `testScrollSteps`.
  - `testExtraModifierStillOpens`: chord plus Shift still opens.
- [x] **Step 2:** Run `--filter TriggerMachineTests`. Expected: FAIL.
- [x] **Step 3:** Implement.
- [x] **Step 4:** Run it again. Expected: PASS.

**Interfaces:**
- Consumes: `Selection`, `PreviewSettings`, `WindowAction.displayName`
- Produces:

    - `current: CGRect?`

  - Format: `"\(Int(w.rounded())) × \(Int(h.rounded())) · <slot>"`.

- **From outline:** `fromOutline = current` when `showNeighbours` is on.
- **Animation:** `animate = morph && !reduceMotion && springResponse > 0`.
- **Switches:** every layer that is switched off produces nil or an empty value.

### Task D3: InputService

**Interfaces:**
- Consumes: `TriggerMachine`, `InputEvent`, `TriggerOutput` (Track B, by signature)
- Produces:
  - `final class InputService: @unchecked Sendable`:
    - `init(chord: TriggerChord, onOutput: @escaping @Sendable (TriggerOutput) -> Void)`
    - `func start() -> Bool`
    - `func stop()`
    - `func updateChord(_ c: TriggerChord)`
- **Event tap:**
  - Created on a dedicated `Thread`, with its own `CFRunLoop`, using `.cgSessionEventTap` and `.headInsertEventTap`.
  - Uses `.defaultTap` (active) for: flagsChanged, keyDown, leftMouseDown, scrollWheel, mouseMoved, leftMouseDragged.
- **Callback:**
  1. Build an `InputEvent`. Compute `pressedModifiers` from the `NX_DEVICE*KEYMASK` bits in the event flags. Convert the location with `CoordinateSpace.pointFromCG` and a `primaryHeight` cached on the tap thread, which `updatePrimaryHeight(_:)` updates from main.
  2. Call `machine.handle`. The machine is confined to the tap thread.
  3. Hand the outputs to `onOutput`, which the coordinator hops to main.
  4. Return nil if `suppress` is true.
- **Tap disabled:** on `tapDisabledByTimeout` or `tapDisabledByUserInput`, re-enable the tap. If that happens more than 5 times in 2 s, pause for 2 s. Shared state is guarded by `OSAllocatedUnfairLock`.

**Coordinator** (`@MainActor`) owns the session:

  - Snapshot the displays.

- **On `apply`:** `WindowService.apply`. If the result is `.failed`, show the HUD "Can't move this window". Hide the overlay.
- **On `cancel`:** hide the overlay.
- **Display change mid-session:** cancel.
